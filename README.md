# oilpaint-cli

把照片转换成油画风格的命令行工具。基于 Sharp 读取图片，再用 Kuwahara 滤镜做保边平滑，叠加画布纹理，输出 PNG / JPEG / WebP。

## 安装

```bash
npm install
```

需要 Node.js >= 18。

## 用法

```bash
oilpaint [选项] <图片...>
```

也可以直接运行：

```bash
node bin/oilpaint.js testdata/5.png
```

### 选项

| 选项 | 说明 |
| --- | --- |
| `-o, --out <path>` | 输出文件或目录，默认 `./oilpaint-output` |
| `-r, --radius <n>` | 笔刷大小，1-24，默认 4（会随图片尺寸自动缩放） |
| `-m, --max <px>` | 处理前的最长边上限，默认 1600 |
| `--texture <0-1>` | 画布与笔触纹理强度，默认 0.35 |
| `-s, --saturation <n>` | 饱和度倍数，0-3，默认 1 |
| `-f, --format <fmt>` | 输出格式：png、jpeg 或 webp，默认与输入一致 |
| `-q, --quality <1-100>` | JPEG / WebP 质量，默认 92 |
| `-c, --concurrency <n>` | 并行处理的图片数量，1-8，默认 2 |
| `-h, --help` | 显示帮助 |
| `-v, --version` | 显示版本 |

### 示例

```bash
# 单张图片，使用默认参数
oilpaint photo.jpg

# 更强的笔触与纹理
oilpaint -r 6 --texture 0.5 -o paintings/ *.jpg

# 输出 WebP 并提高饱和度
oilpaint -f webp -s 1.2 -o out.webp portrait.png
```

## 工作原理

1. **限尺寸**：先用 Sharp 按 EXIF 方向旋转、铺白底、转 sRGB，并把最长边缩到 `--max` 以内。
2. **Kuwahara 滤镜**：每个像素在周围 4 个象限里取方差最小的区域，用其平均色替换。这样皮肤、树叶等细节被压平成笔触色块，同时边缘保持清晰。使用积分图（summed-area table）实现，单像素耗时与半径无关。
3. **饱和度调整**：按亮度对 RGB 做饱和度缩放。
4. **画布纹理**：叠加斜向亚麻纹、细颗粒和较大范围的颜料不匀，形成油画布质感。

### 分辨率自适应

笔刷半径和纹理尺度都随图片尺寸缩放，而不是固定像素值。半径以 400px 参考边为基准换算，纹理的经纬周期和噪声尺度按最长边计算。这样无论输出 800px 还是 1600px，油画感看起来一致，不会在大图上"消失"。

## 调参建议

- 想要更明显的笔触：调大 `-r`。
- 想要更粗的颜料块：`-r 8` 以上。
- 只想轻微柔化：`-r 2` 或 `-r 3`。
- 纹理太脏：调低 `--texture`，例如 `0.15`；想要明显的画布感可到 `0.6`。
- 颜色更鲜艳：`-s 1.2` 到 `1.4`。
